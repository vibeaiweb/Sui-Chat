# 聊天機器人使用說明

## 功能概述

Sui Chat 現在支援聊天機器人功能！您可以在聊天中 @提及機器人來獲取 AI 回應。

## 可用的機器人

### 【Lucky Vicky】張員瑛
- **名稱**: Lucky Vicky
- **描述**: AI 助手 - 張員瑛
- **提及方式**: `@Lucky Vicky` 或 `@【Lucky Vicky】張員瑛`

## 使用方式

### 1. 基本用法

在聊天輸入框中輸入：
```
@Lucky Vicky 請問什麼是 Sui？
```

### 2. 完整流程

1. **發送問題**: 您輸入包含 @機器人 的訊息
2. **第一次簽名**: 簽名發送您的問題到鏈上
3. **機器人處理**: 系統調用機器人 API 獲取回應
4. **第二次簽名**: 簽名發送機器人回應到鏈上
5. **完成**: 所有人都能看到問題和機器人的回應

### 3. 機器人回應格式

機器人的回應會包含：
```
🤖 【Lucky Vicky】張員瑛

回覆 @您的用戶名: 您的問題

機器人的回應內容...
```

## 注意事項

⚠️ **重要**：
- 每次提及機器人需要簽名 **2 次**（1次問題 + 1次回應）
- 需要支付 **2 次 gas fee**
- 機器人回應需要上傳到 Walrus，需要消耗 WAL tokens
- 機器人回應會自動發送到聊天室，所有人都能看到

💡 **提示**：
- 可以同時提及多個機器人（如果配置了多個）
- 機器人回應失敗時會顯示錯誤訊息
- 所有機器人互動都會記錄在鏈上

## 添加新機器人

開發者可以在 `src/config/bots.ts` 中添加新的機器人配置：

```typescript
{
  name: 'Bot Name',
  displayName: '顯示名稱',
  apiEndpoint: 'https://your-bot-api.com/webhook',
  description: '機器人描述',
  avatar: 'https://avatar-url.com/image.png', // 可選
}
```

### API 要求

機器人 API 需要支援以下格式：
- **URL**: `https://your-api.com/endpoint?text=問題&userid=用戶名`
- **方法**: GET
- **回應**: JSON 或純文字

### API 回應格式

JSON 格式（推薦）：
```json
{
  "response": "機器人的回應內容"
}
```

或純文字格式：
```
機器人的回應內容
```

## 故障排除

### 機器人沒有回應
- 檢查網路連接
- 查看瀏覽器控制台是否有錯誤訊息
- 確認機器人 API 是否正常運作

### 簽名失敗
- 確認錢包已連接
- 確認有足夠的 SUI 和 WAL tokens
- 檢查網路狀態

### 機器人回應錯誤
- 機器人會自動發送錯誤訊息到聊天室
- 查看控制台獲取詳細錯誤信息
- 稍後重試
